# Rock Paper Scissors Game

## Overview

This is a console-based Rock Paper Scissors game developed in Java. The user competes against the computer, which generates random moves. The game continues until the user chooses to exit.

## Features

* User vs Computer gameplay
* Random computer move generation
* Input validation
* Win, Lose, and Draw detection
* Exit option

## Technologies Used

* Java
* Scanner Class
* Random Class

## How to Run

1. Clone the repository.
2. Open the project in your preferred Java IDE.
3. Compile and run the Java file.
4. Enter Rock, Paper, or Scissors to play.
